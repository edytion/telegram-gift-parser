## v0.1.0 — 2026-10-24

### Русский

Первый публичный выпуск Telegram Gift Parser.

- Сбор данных коллекционных подарков через Telegram API и Telethon.
- Проверка одного подарка или сбор по найденным коллекциям.
- JSONL-файлы по коллекциям и единая база.
- Продолжение сбора и обновление с сохранением истории снимков.
- Настройка нескольких аккаунтов через консоль, отдельные файлы сессий.
- Русский и английский интерфейс с сохранением выбора языка.
- Обработка FLOOD_WAIT, остановка при обнаружении критических ошибок и журналы.
- START.bat, документация RU/EN, скриншоты и лицензия MIT.

Полнота каталога не гарантируется. Паузы и обработка ошибок не защищают аккаунты от ограничений Telegram.

### English

First public release of Telegram Gift Parser.

- Collectible gift data through the Telegram API and Telethon.
- Single-gift checks or collection across discovered collections.
- Per-collection JSONL files and a combined database.
- Resumable collection and refresh with snapshot history.
- Interactive multi-account setup with separate session files.
- English and Russian CLI with a saved language preference.
- FLOOD_WAIT handling, logs and a stop on detected critical errors.
- Windows launcher, RU/EN documentation, screenshots and MIT license.

Catalog coverage is not guaranteed. Request pauses and error handling do not protect accounts from Telegram restrictions.
